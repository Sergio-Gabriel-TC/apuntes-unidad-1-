# Unidad 1: Introducción a la Graficación por Computadora
Caracterización de la Asignatura
Esta materia es fundamental para nuestro perfil como Ingenieros en Sistemas, ya que nos da las herramientas para diseñar modelos que solucionen problemas mediante el uso de matemáticas. El objetivo es que aprendamos a crear interfaces visuales atractivas, entendiendo desde los bits hasta la realidad virtual.

# 1.1. Historia y evolución de la graficación por computadora

Origen: La graficación surge de la necesidad de pasar de sistemas puramente textuales a entornos visuales.


Evolución: Ha transitado desde el trazado de líneas simples en terminales vectoriales hasta la manipulación compleja de objetos 3D y entornos de simulación.


Hito: El desarrollo de algoritmos de rasterización permitió que las computadoras personales manejaran interfaces gráficas modernas.

# 1.2. Áreas de aplicación
La graficación no es solo para juegos; impacta en múltiples sectores profesionales:

Simulación y Capacitación: Entrenamiento en entornos controlados (vuelo, maquinaria).

Medicina: Visualización de imágenes diagnósticas y modelos anatómicos.

Arte y Entretenimiento: Cine, videojuegos y diseño digital.

Noticias y Publicidad: Gráficos informativos y visualización de datos.

# 1.3. Aspectos matemáticos de la graficación
Para que el software funcione, necesitamos una base sólida:

Álgebra Lineal: Matrices de transformación para posicionar objetos.

Cálculo y Geometría: Definición de curvas, superficies y el comportamiento de la luz.

# 1.4. Modelos del color: RGB, CMY, HSV y HSL
Representan el "ADN visual" de cómo la computadora interpreta la luz:

RGB (Red, Green, Blue): Modelo aditivo para pantallas.

CMY (Cyan, Magenta, Yellow): Modelo sustractivo para impresión física.

HSV y HSL: Basados en Matiz (Hue), Saturación (Saturation) y Brillo/Luminosidad (Value/Lightness) para facilitar la selección de color humana.

# 1.5.1. Formatos de imagen

Un formato de imagen es un método estandarizado para organizar y almacenar datos de imagen digital. En graficación, la elección del formato depende de si necesitamos precisión matemática (vectores) o realismo fotográfico (mapas de bits).

# A. Clasificación Principal

Mapas de Bits (Raster): Formados por una rejilla de píxeles. Son ideales para representar escenas complejas y efectos de iluminación como el sombreado Phong o Gouraud.

Imágenes Vectoriales: Basadas en funciones matemáticas (puntos, líneas y curvas como Bézier). No pierden resolución al escalarse, lo que las hace vitales para el diseño de fuentes de texto y logotipos.

# C. Formatos Vectoriales y Especializados

SVG (Scalable Vector Graphics): Basado en XML, esencial para gráficos 2D en programación web y móvil.

Formatos de Intercambio 3D: Aunque son modelos, archivos como .OBJ o .STL almacenan la geometría de mallas poligonales para su posterior renderizado con materiales y texturas.

Formatos: Estándares para almacenar datos visuales (como PNG, JPEG, BMP).
